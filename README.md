# Diurnal Temperature Range Trends in St. John's, NL (2000-2025)

Analysis of diurnal temperature range (DTR) trends in St. John's, Newfoundland and Labrador to test for monotonic changes consistent with global warming theory.

## Data Source

**Provider:** [ClimateData.ca](http://climatedata.ca/) (Environment and Climate Change Canada)

**Stations:** Two meteorological stations in St. John's region

PS: Station coordinates and names available in raw data file

**Period:** January 1, 2000 – December 1, 2025

**Variables:**

- `MIN_TEMPERATURE` (°C)
- `MAX_TEMPERATURE` (°C)
- `MEAN_TEMPERATURE` (°C)
- Additional climate variables (precipitation, snow, etc.)

## Methods Summary

### Data Preparation

1. Load raw daily temperature data
2. Remove 2 invalid records where T_min > T_max
3. Calculate DTR = T_max - T_min
4. Add temporal features (month, year)

### Statistical Tests

- **Mann-Kendall test:** Non-parametric test for monotonic trends (α=0.05)
- **Linear regression:** Estimate trend magnitude and direction
- **Extreme event analysis:** 90th/10th percentile thresholds

### Key Findings

- **Temperature:** Significant warming trend (+1.07°C over 26 years, p<0.001)
- **Annual DTR:** No significant trend (p=0.229)
- **Extreme events:** No significant trends in high or low extremes
- **Seasonal pattern:** 3.6°C amplitude; spring DTR > fall DTR
